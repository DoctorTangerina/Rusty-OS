# Rusty-OS

## An OS made in Rust

This project’s purpose is to try and create something that will help me get used to Rust language and for me to learn about kernel and how operational systems works by creating the features by hand (no AI code). It is being done with the help of *blog\_os* project tutorial.

### Roadmap

- [X] VGA Terminal
- [ ] Testing  
- [ ] CPU Exceptions  
- [ ] Double Faults  
- [ ] Hardware Interrupts  
- [ ] Paging  
- [ ] Heap Allocation  
- [ ] Async

There’s also other small things that were not covered in *blog\_os* tutorial, which I’ll be trying to add.

### List of additional features

- [ ] UEFI support  
- [ ] Write own boot, compatible with Multiboot and others
- [ ] TBTO (to be thought of)
